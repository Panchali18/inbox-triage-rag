# Revenue.ie guidance (public source)

Information provided courtesy of the Revenue Commissioners under a [Creative Commons Attribution 4.0 International (CC BY 4.0) licence](https://www.revenue.ie/en/corporate/using-revenue/reuse-of-public-sector-information/public-sector-information-licence.pdf).

This project is a portfolio demonstration. It is not affiliated with or endorsed by the Revenue Commissioners. These pages are general public guidance, not advice from the fictional firm, and they may have changed since they were saved. Always check the source page for the current position.

## How these files were made

1. I saved each page from revenue.ie as a PDF on 15 October 2026.
2. I converted the text to Markdown. I removed only the section menus, "Sign in to ROS/myAccount" buttons, "[PDF]" link labels and the page header.
3. I compared each file word by word with its PDF. The only other changes rejoin two words split by line breaks ("pre-preceding", "cross-border").
4. The PDFs are not stored in this repo, because they contain Revenue's logo. The licence does not cover logos, crests or official symbols.
