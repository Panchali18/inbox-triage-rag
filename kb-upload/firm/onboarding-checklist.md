# Nore Valley Accountants: Onboarding and Annual Records Checklists

We use these checklists to request documents. A partner reviews identity documents and makes every identity verification decision. Staff and systems only request and log documents. They never approve or reject identity.

Each item has a code. The client table tracks each code as `received` or `outstanding`.

## A. New client onboarding: individuals and sole traders

| Code | Document | Notes |
|---|---|---|
| ON-ID | Photo identification | Current passport or driving licence |
| ON-ADDR | Proof of address | Utility bill or bank statement dated within the last 6 months |
| ON-PPSN | PPSN | Shown on a Revenue document or a payslip |
| ON-PRIOR | Previous year's tax return or Revenue statement of liability | If available |
| ON-ROS | Tax agent link authorisation | We send the request; you approve it |
| ON-EL | Signed engagement letter | We send it with your quote |

## B. New client onboarding: limited companies

All of section A for **each director**, plus:

| Code | Document | Notes |
|---|---|---|
| CO-CERT | Certificate of incorporation | From the CRO |
| CO-CONST | Company constitution | |
| CO-BEN | Beneficial ownership details | Anyone owning or controlling more than 25%, with ID and proof of address for each |
| CO-PRIORACC | Previous year's financial statements and CT1 | If the company has filed before |
| CO-ROS | Tax agent link authorisation for the company | |

## C. Annual records: sole traders (due by 31 August)

| Code | Document |
|---|---|
| ST-BANK | Business bank statements for the full tax year |
| ST-SALES | Sales records or invoices issued |
| ST-EXP | Expense receipts and purchase invoices |
| ST-MOTOR | Motor and travel log, if claiming vehicle expenses |
| ST-ASSET | Invoices for equipment or other assets bought |
| ST-PENSION | Pension contribution certificates, if any |
| ST-RENT | Rental income and expense summary, landlords only |

## D. Annual records: limited companies (due within 3 months of year end)

| Code | Document |
|---|---|
| LC-BANK | Company bank statements for the full financial year |
| LC-LEDGER | Bookkeeping export (sales and purchase ledgers) |
| LC-PAYROLL | Payroll summary for the year |
| LC-STOCK | Stock valuation at year end, if applicable |
| LC-LOANS | Loan statements and director's loan account details |
| LC-ASSET | Fixed asset purchases and disposals |
| LC-DIRINFO | Confirmation of current directors and shareholders |

## How we request missing items

When documents arrive, we log each one against its code and tell the client which items are still outstanding, using the item names in this checklist. We never tell a client their identity has been verified. A partner confirms that separately.
